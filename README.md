# ستوديو كورة الناصرية

منصة ويب تفاعلية لتوليد برومبتات تصميم مباريات كرة القدم، مع محرك تحليل دقيق يقيّم جودة التحليل المرجعي قبل إنتاج البرومبت النهائي.

## ماذا يفعل المشروع؟

- يحوّل وصف التحليل البصري لأي بوستر مرجعي إلى برومبت إنتاجي احترافي.
- يقيس اكتمال التحليل بنسبة مئوية بناءً على 6 محاور جودة.
- يقدّم تقرير فجوات واضح مع توصيات مباشرة لتحسين النتيجة.
- يدعم حفظ البرومبتات وسجل التحليلات محليًا داخل المتصفح.

## المحاور التحليلية داخل الصفحة

- الخطوط والهرمية
- الألوان والإضاءة
- التكوين والبنية
- الإخراج والمؤثرات
- وضوح المحتوى النصي
- معايير جودة التشغيل

## طريقة الاستخدام

1. افتح الصفحة الرئيسية.
2. الصق تحليل التصميم المرجعي أو اختر قالبًا جاهزًا.
3. راقب نسبة الاكتمال في محرك التحليل الدقيق.
4. عالج الفجوات الظاهرة في التقرير حتى ترتفع الجودة.
5. أدخل بيانات المباراة.
6. أنشئ البرومبت النهائي ثم انسخه أو حمّله.

## ملاحظات مهمة

- كلما كان التحليل المرجعي أطول وأكثر تنظيمًا كانت النتيجة أدق.
- التقييم الموصى به قبل الاعتماد النهائي: 70% فما فوق.
- البيانات تُحفظ عبر LocalStorage في نفس المتصفح والجهاز.
